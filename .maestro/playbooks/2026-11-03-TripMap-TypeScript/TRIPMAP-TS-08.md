**Target architecture (decided; do not change it).**
- One TypeScript npm-workspaces monorepo. Root `package.json` has `"workspaces": ["packages/*"]`. Packages: `packages/core` (`@tripmap/core`: types, YAML, detection, geometry, SVG building; it must run in Node AND the browser), `packages/cli` (`tripmap`, the npm package and `bin`), `packages/web` (Vite + React + TypeScript editor, moved from `web/` in phase 08).
- Node-only code lives under `packages/core/src/node/`. The browser bundle must never import anything from `src/node/`. Photos is read only in Node.
- Rendering: `buildSvg` in core makes the SVG. Node rasterizes it with `@resvg/resvg-js`. The browser rasterizes it with canvas. No Chrome, no ImageMagick.
- Local mode: `tripmap serve` (Node) binds `127.0.0.1`, serves the built web app, and exposes `GET /api/photos/status`, `POST /api/detect` (dates in, trip and stats out), `POST /api/yaml`. The app's Detect button calls it. Default port 8787 (8000 is the old FastAPI server; do not use it).
- Hosted mode: a static build for GitHub Pages (`VITE_MODE=hosted`, base path `/tripmap/`). It shows the date form, then generates `npx --yes tripmap@<VERSION> draft --from <A> --to <B> --port <P> --token <T>`. P is random in 49152–65535; T is 16 random hex characters from `crypto.getRandomValues`. The page then polls `http://127.0.0.1:<P>/trip?token=<T>` every 1.5 seconds for up to 10 minutes. The CLI's listener is one-shot (see phase 07). A paste box is the fallback.
- Hosted page origin: `https://stephengolub.github.io`. It is the only origin allowed to read the listener. Also allow `http://localhost:5173` for development.
- YAML and JSON trip format is unchanged from the Python version (`docs/trip-format.md`), including the `enabled` flag on each leg.
- npm package name `tripmap` (free as of 2026-11-03). Start at version `1.0.0` in `packages/cli/package.json`. `engines.node` is `>=22.5`.

**Style is fixed (CLAUDE.md).** White roads, red pins for overnights, gold stars for quick stops, train legs as a white track with cross-ties and a train badge, dashed boat and flight legs with ship and plane badges, navy land at 45% with a white coast. Do not add style options.
